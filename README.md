# Viáticos Sistronic

App web (PWA) para el control de gastos y la legalización de viáticos (formato FO-AD-03).

- Abrir: https://proyectos1-collab.github.io/viaticos-sistronic/
- Los gastos y las fotos se guardan solo en el celular (almacenamiento del navegador). Este repositorio no contiene datos.
- `fuente/`: código fuente; `python3 build.py` genera `index.html`.
